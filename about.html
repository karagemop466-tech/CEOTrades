How CEOTrades works

Fully automated collection, organization and analysis of insider trading disclosures. No manual data entry, ever.

1 · Data source

All data comes from the U.S. SEC EDGAR system:

  • Form 4 — Statement of Changes in Beneficial Ownership, filed within 2 business days of any insider transaction.
  • Form 5 — annual statement that catches transactions not previously reported.
These are the official disclosure forms under Section 16 of the Securities Exchange Act of 1934 — every director, executive officer and >10% shareholder of a public company must file them.

2 · Enumeration

Each day the pipeline reads the SEC’s daily master index (sec.gov/Archives/edgar/daily-index/YYYY/QTRq/master.YYYYMMDD.idx) to list every Form 4/5 filed that day, with the EDGAR full-text search API (efts.sec.gov) as an automatic fallback and cross-check.

3 · Extraction

Each filing’s structured XML is downloaded and parsed (issuer, insider, relationship, and every non-derivative and derivative transaction: date, code, shares, price, shares after).

4 · Paper book

Every non-derivative open-market purchase (code P) of common equity becomes a simulated $10,000 long, filled at the next regular-session open after the filing date. The insider’s own price is stored only for the delay-gap comparison — it is never our fill. Positions stay open and are marked to the latest Yahoo / Stooq / Nasdaq close.

5 · Storage & publishing

Rows are merged into a growing dataset (amendments supersede originals), the paper book is re-marked, and this static site is regenerated and committed by GitHub Actions every night at 04:00 UTC — after EDGAR’s nightly index build. The site deploys automatically via GitHub Pages.

Caveats

  • “Net flow” = code P value minus code S value. Grants (A), exercises (M) and tax withholding (F) change holdings but are not open-market flow.
  • Many sales follow pre-arranged 10b5-1 plans; the data shows the trade, footnotes on EDGAR explain the plan.
  • Some transactions are reported without a price (grants, gifts) — value is blank, not zero.
  • Amendments (4/A) supersede the original filing; the latest version is kept.
  • Filings for issuers with no U.S. ticker still appear (ticker shown as —).

Paper-book caveats

  • No commissions, borrow, or bid/ask beyond using the next open.
  • Private purchases (still code P) are treated like open-market buys because Form 4 does not split them.
  • Tickers Yahoo/Stooq/Nasdaq do not price stay no_price — they are never silently filled.
  • Filing-day prices are never the fill. If the next session has not printed, status is awaiting_entry.
